# Creditreconn

**We Do Our Homework**

Creditreconn is a credit counseling and financial education company. We use technology to help people understand their credit, build everyday money skills, and work toward financial independence.

| Learning phase | What a learner practices |
| --- | --- |
| Financial Awareness | Read a credit report, review spending, and identify one habit to change. |
| Financial Literacy | Build a budget, compare borrowing costs, and set a savings goal. |
| Financial Freedom | Turn those skills into a longer-term plan for saving, debt repayment, or entrepreneurship. |

## Visa Developer project

Our proposed sandbox project, **Creditreconn Learning**, explores course discovery, enrollment, and progress tracking with Visa Practical Money Skills. The [sandbox plan](docs/visa-integration-plan.md) includes the project description and first test.

This public repository documents the proposed integration. Portal setup and API testing are pending. Keep customer records, payment information, and API credentials outside this repository.
