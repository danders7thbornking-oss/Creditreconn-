## Project description

Creditreconn uses technology to teach financial awareness, financial literacy, and financial freedom. In the sandbox, we plan to test how a sample learner can find a financial education course, enroll, and track progress. We will use fictional learner data.

## First sandbox test

1. Create the Creditreconn Learning project and select the Practical Money Skills product if it is available in the account.
2. Use the product documentation to configure sandbox authentication on the server. Keep credentials outside GitHub.
3. Retrieve the courses available to a fictional learner and record the starting enrollment status.
4. Enroll the learner in a test course, retrieve enrollment again, and verify that the course is listed for that learner.
5. Check what progress information the sandbox exposes and record the observed result before designing the client progress screen.

Portal setup and API testing are pending. Product availability in this account has yet to be verified.
